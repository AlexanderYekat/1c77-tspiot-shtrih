# 1c77-kkt-fmu-bridge-tspiot

Интеграционный мост для 1С 7.7, FMU API и ККТ.

Проект предназначен для схемы, в которой 1С 7.7 не работает напрямую с кассовым аппаратом, а передаёт команды во внешний proxy-сервис. Proxy-сервис выполняет две функции:

* пересылает запросы проверки маркированных товаров в FMU API;
* передаёт команды печати чеков, закрытия смены и получения информации о ККТ в локальную Delphi/Pascal-программу, установленную на том же компьютере, что и касса.

Основная цель проекта — вынести работу с ККТ и разрешительным режимом маркировки из 1С 7.7 во внешний сервисный слой, сохранив совместимость со старой логикой печати чеков.

## Состав

* `1cv77` — фрагменты кода 1С 7.7 для отправки чеков во внешний proxy-сервис.
* `proxy-1c-fmuapi` — C# proxy-сервис для маршрутизации запросов между 1С, FMU API и локальным модулем печати.
* `rab-part-shtrih-sripts` — Pascal/Delphi-фрагменты работы с ККТ через драйвер Штрих/DrvFR.

## Схема работы

```text
1С 7.7
  -> proxy-1c-fmuapi
      -> FMU API: проверка марок
      -> Delphi/Pascal KKT module: печать чека на ККТ
```
